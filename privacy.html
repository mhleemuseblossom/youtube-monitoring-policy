[운영 조직명](이하 “운영자”)은 콘텐츠 저작권 모니터링 시스템(이하 “서비스”)을 운영하며 관련 법령과 YouTube API Services 정책에 따라 데이터를 처리합니다. 본 방침은 서비스에서 어떤 데이터를 어떤 목적으로 처리하고, 어떻게 갱신·삭제하는지 설명합니다.

1. 서비스 및 YouTube API Services 사용

본 서비스는 저작권 보호를 위한 공개 콘텐츠 모니터링에 YouTube API Services를 사용합니다. YouTube에서 공개적으로 제공되는 동영상 및 채널 정보를 조회하여 잠재적 저작권 침해 의심 콘텐츠를 검토하고 내부 리포트를 작성합니다.

  • Google 개인정보처리방침
  • YouTube 서비스 약관
  • YouTube API Services 이용약관

2. 데이터 항목과 수집 방법

서비스는 YouTube Data API를 통해 공개적으로 조회할 수 있는 동영상 ID와 URL, 제목, 설명, 게시일, 채널 ID·이름, 조회수 등 공개 메타데이터를 수집할 수 있습니다. 수집 범위는 실제 모니터링 목적에 필요한 항목으로 제한합니다.

현재 서비스 구성 전제: Google OAuth 로그인을 제공하지 않고, API 키를 사용해 공개 데이터만 조회하는 내부 업무 도구입니다. 향후 계정 연동 또는 비공개 사용자 데이터 접근 기능을 추가하면 이 방침을 개정합니다.

3. 처리 목적

  • 아티스트 및 곡명 관련 공개 YouTube 콘텐츠 검색
  • 공식·협력 채널의 공개 콘텐츠와 비교
  • 비공식 업로드, 재편집 등 검토 대상 콘텐츠 분류
  • 저작권 모니터링 현황 및 분석 리포트 작성

자동화된 분류 자체가 저작권 침해의 법적 확정을 의미하지는 않습니다.

4. 보관, 갱신 및 삭제 정책

운영자는 YouTube API를 통해 취득한 데이터에 적용되는 최신 YouTube API 정책을 따릅니다. 일반적인 공개 API 데이터는 정책상 허용된 기간 내에 갱신하거나 삭제하며, 통상 30일 이내 재확인·갱신 또는 삭제가 필요한 항목을 별도로 관리합니다. 정책상 더 짧은 기간 또는 즉시 삭제가 요구되는 경우 해당 조건을 우선합니다.

삭제되었거나 비공개로 변경되어 더 이상 제공되지 않는 동영상 정보는 API 정책과 적용 법령에 따라 갱신 또는 삭제합니다. 내부 분석 보고서, 백업 및 파생 데이터에도 적용 가능한 보관·삭제 요건을 검토합니다.

실제 운영 주기: [예: 24시간마다 신규 영상 수집, 30일 이내 API 정보 재확인, 삭제 요청 접수 후 검토 절차 — 실제 구현에 맞게 수정]

5. 공유 및 제3자 제공

수집된 정보는 저작권 보호 업무와 관련된 내부 승인 담당자에게만 접근을 허용하는 것을 원칙으로 합니다. 외부 제공이나 위탁이 발생하는 경우 관련 법령과 YouTube API 정책이 허용하는 범위에서 처리하며, 필요한 경우 본 방침을 갱신합니다.

6. 개인정보 보호 및 보안

서비스의 API 접근 정보와 내부 보고서에 대한 접근을 승인된 담당자로 제한하고, 필요한 기술적·관리적 보안 조치를 적용합니다. 개인 식별 가능 정보가 포함되는 경우 관계 법령에 따라 처리합니다.

데이터 처리 관련 문의 또는 삭제 요청은 아래 이메일로 접수할 수 있습니다. 운영자는 요청 대상과 적용 규정을 확인하여 필요한 정정·삭제 또는 안내를 진행합니다.
